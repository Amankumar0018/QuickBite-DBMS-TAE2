# QuickBite: Food Delivery & Restaurant Management Database System

## TAE-2 DBMS Project

QuickBite is a MySQL-based database system for managing customers, addresses, restaurants, menu items, orders, payments, delivery partners, deliveries, reviews, and administrators.

## Database
- RDBMS: MySQL
- Development Tool: MySQL Workbench

## Project Files
- `schema.sql` — database, tables, constraints, primary keys and foreign keys
- `data.sql` — realistic sample data (100+ records per table)
- `queries.sql` — joins, subqueries, aggregates, views, stored procedure and trigger
- `performance.sql` — EXPLAIN queries and indexing demonstration

## Main Tables
Customer, Address, Restaurant, MenuItem, Orders, OrderItem, Payment, DeliveryPartner, Delivery, Review, Administrator

## TAE-2 Features
- DDL and constraints
- 100+ records per core table
- Inner, outer and self joins
- Correlated subqueries
- GROUP BY and HAVING
- Two reporting views
- Parameterized stored procedure
- Trigger for automated order-status handling
- Composite indexes
- EXPLAIN-based performance analysis
